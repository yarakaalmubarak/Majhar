How we test Majhar

We create shop crises the AI agent has never seen, let it handle them on its own, and then check every single customer against what really happened to them.

The AI agent worksIt finds the cause, fixes it, repairs or refunds each customer, and asks a person before any refund over 300 SAR.
Check against the truthThe simulator secretly knows each customer's real outcome. The agent never sees it; it is only used for grading.

What testing caught, and how it was fixed

Each problem was found by a test, fixed, and checked again on crises that had not been looked at.

  1. A mistyped tool call looked like the AI was downIn a live run, Groq rejected one AI answer because a plan was missing its steps, and the problem went to the backup. The connection now retries, and the agent tells the AI which values are allowed so it can correct itself.
  2. Too many tickets were handed to a personWith the real AI, some problems were left without a plan. The AI is now reminded of unfinished problems, must try a plan before handing customers over, and the reason for every hand-over is recorded.
  3. The first full test with the real AI ran out of the free provider's limitsGroq's free tier allows 8,000 tokens a minute and 200,000 a day. Each AI call re-sent the whole conversation, so the AI went silent and most tickets were handed to people (8% fixed under strict rules). Fixed: calls are about 3 times smaller, the agent waits out per-minute limits, and if the AI is still unavailable the company's standard playbook takes over, clearly marked as backup. Every run now reports the tokens the AI used.
  4. The first AI version was impatientIt re-sent tickets before the system was ready and gave up on solvable cases. Each tool now tells the AI what happens next and when to wait.
  5. One AI call per customer would not survive a rushThe AI now plans once per problem and automation applies the plan to every customer, so a crowd costs the same few AI calls.
  6. A customer hurt again after their ticket closed went unnoticedTickets now reopen automatically. On fresh crises, wrongly closed tickets went from 1 to 0.
  7. A fix that kept failing was retried foreverNow three real failures hand the case to a person, with the full history.
  8. Two approvals on one problem overwrote each otherSome customers waited forever. Approvals are now tracked once per booking and per problem.
  9. One check read data a real agent could never seeRemoved. A test now forbids the agent from reading the simulator's hidden truth.
